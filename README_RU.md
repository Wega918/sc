# SC Battle Lab

## Версия со всеми юнитами

В проект подключены 108 файлов `chr_*`. Данные каждого бойца загружаются только
после выбора его карточки, поэтому открытие страницы не загружает все SC сразу.
HTML можно открывать двойным кликом: runtime JSON упакованы в JavaScript-обёртки,
для работы `fetch()` и локальный сервер не требуются.

Движок воспроизводит оригинальные export-анимации `run/walk/fly`, `idle` и
`attack`, включая вложенные MovieClip, кадры, матрицы, UV, alpha и blend mode.
Юниты выбирают ближайшую живую цель, поворачиваются, идут к ней и атакуют.
Для дальнобойных бойцов добавлен полёт снаряда, для попаданий и разрушений —
частицы. Звуки используются только из присутствующих SFX и только из уже
сопоставленного каталога; случайные звуки неподходящим войскам не назначаются.

## Атласы в облегчённом архиве

Чтобы итоговый архив не весил сотни мегабайт, папка
`public/assets/atlases/` может отсутствовать. Оставьте свою существующую папку
с атласами на месте либо скопируйте её в проект после распаковки обновления.
Ожидаемый путь, например:

`public/assets/atlases/chr_barbarian/chr_barbarian_0.webp`

Файлы звуков, runtime SC и код движка входят в архив.

Готовый автономный прототип веб-поля боя. Откройте `index.html` двойным кликом: локальный сервер не нужен.

## Что уже работает

- изометрическое поле и сетка;
- карточки всех юнитов, для которых найден каталог `textures/chr_*`;
- выбор и высадка любого юнита;
- поиск ближайшей живой цели, движение, атака, урон и уничтожение цели;
- оригинальная SC-анимация бега/атаки варвара из проверенной демки;
- звуки OGG по найденным совпадениям имён;
- все исходные декодированные SC JSON, runtime CSV JSON, WebP-атласы и SFX сохранены в понятной структуре.

## Важное ограничение

`public/data/sc/*.json` — это экспорт контейнера, строк и контрольных данных. Он не содержит полностью разобранных `shapes / UV / matrices / frames`. Поэтому оригинально собирается только варвар, для которого в `public/demo/barbarian/data.js` уже имеются эти структуры. Остальные юниты представлены игровыми маркерами, но их логика полностью работает.

Чтобы включить оригинальный рендер остальных юнитов, нужно получить из каждого `.sc` структуру того же уровня, что `public/demo/barbarian/data.js`, после чего добавить универсальный загрузчик банков SC. Переделывать выбор, движение, цели и бой не потребуется.

## Структура

- `index.html` — автономная точка запуска;
- `src/js/app.js` — игровая логика и сцена;
- `src/js/sc-renderer.js` — Canvas-рендер полигонов SC;
- `public/data/runtime/unit-catalog.js` — готовый браузерный каталог;
- `public/data/csv/` — компактные JSON из CSV;
- `public/data/sc/` — экспорт декодированных SC;
- `public/assets/atlases/` — WebP-атласы;
- `public/assets/audio/sfx/` — OGG;
- `public/demo/barbarian/` — полностью рабочий эталон SC-рендера;
- `tools/build_catalog.py` — пересборка каталога после добавления ресурсов;
- `docs/` — карта ресурсов и технический отчёт.

## Про звуки

В предоставленных `animations.json` и SC JSON нет проверенной таблицы, напрямую назначающей OGG событиям юнита. `unit-catalog.js` сопоставляет подходящие deploy/attack/death-файлы по имени. Для точного воспроизведения как в оригинале понадобится отдельная таблица аудиособытий либо её источник из игровых данных.
