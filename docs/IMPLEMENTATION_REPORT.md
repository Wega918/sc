# Отчёт по интеграции

## Проверенные связи

1. `animations.json` содержит группы, действия, `exportName` и путь вида `sc/chr_barbarian.sc`.
2. Каталог `textures/chr_*` содержит соответствующие WebP-атласы.
3. `decoded_sc_json` содержит имена экспортов, но не готовые полигоны, UV, матрицы и покадровое дерево.
4. `sfx/*.ogg` содержит узнаваемые deploy/attack/death-файлы, однако прямых назначений звука анимационным событиям в переданном наборе не найдено.

## Принятое решение

Игровая симуляция отделена от представления. Любой юнит уже может выбираться, высаживаться, искать ближайшую цель, двигаться и наносить урон. Рендерер выбирается полем `renderMode`: `sc` для полноценного SC-банка и `marker` для ещё не разобранного банка.

Это позволяет постепенно добавлять разобранные SC-анимации без переписывания боя.
